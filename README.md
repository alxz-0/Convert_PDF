# 📄 PDF to All Converter

Aplikasi desktop sederhana untuk mengubah file PDF ke berbagai format hanya dengan beberapa klik. Dibuat menggunakan Python dan PySide6 sebagai proyek pembelajaran dan pengembangan keterampilan selama menempuh pendidikan di bidang Data Science.

---

## ✨ Fitur

* 📄 **PDF → DOCX** (Word)
* 📊 **PDF → XLSX** (Excel)
* 📝 **PDF → TXT** (Text)
* 🌐 **PDF → HTML**
* 🖼️ **PDF → PNG**
* 🖼️ **PDF → JPG**
* ⏳ **Progress Bar**
* 🖥️ **Antarmuka Desktop** yang mudah digunakan
* 🔒 Berjalan secara **Offline**
* 🔓 **Open Source**

---

## 🎯 Tujuan Aplikasi

Aplikasi ini dibuat untuk membantu pengguna yang ingin mengubah dokumen PDF ke format lain tanpa harus menggunakan website online. Dengan aplikasi ini, data tetap berada di komputer pengguna sehingga lebih aman untuk dokumen pribadi maupun dokumen akademik.

---

## 🖥️ Cara Menggunakan

### Langkah 1
Jalankan aplikasi:
```text
PDF Converter.exe
```

### Langkah 2
Klik tombol:
```text
Choose PDF File
```

### Langkah 3
Pilih file PDF yang ingin dikonversi.
Contoh:
```text
Laporan.pdf
```

### Langkah 4
Pilih format tujuan.
Contoh:
- ☑ DOCX
- ☑ XLSX
- ☑ JPG

### Langkah 5
Klik tombol:
```text
Convert
```

### Langkah 6
Tunggu hingga proses selesai. File hasil konversi akan otomatis tersimpan pada folder:
```text
D:\Result-Converted-Files
```

---

## 📁 Contoh Hasil

**Input:**
```text
Laporan.pdf
```

**Output:**
```text
Laporan.docx
Laporan.xlsx
Laporan.txt

Laporan_png/
├── page_1.png
└── page_2.png

Laporan_jpg/
├── page_1.jpg
└── page_2.jpg
```

---

## ⚠️ Catatan

* Hasil konversi bergantung pada struktur file PDF.
* Dokumen PDF yang berisi gambar atau tabel kompleks mungkin tidak selalu dapat dikonversi secara sempurna.
* Beberapa format seperti DOCX dan XLSX berfokus pada ekstraksi konten, bukan menyalin tata letak secara identik.
